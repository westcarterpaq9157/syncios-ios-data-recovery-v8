## What Is SynciOS Data Recovery?

SynciOS Data Recovery is a Windows desktop utility for examining and recovering content from iPhone, iPad, and iPod devices. It can scan an available device directly, or work with data stored in iTunes and iCloud backups.

The recovery process is designed to help you identify useful content before exporting it. Read-only scanning provides a non-destructive way to inspect results, while selective recovery lets you choose individual entries rather than handling every available item.
